This is a **console application** in Kotlin to convert between decimal and binary numbers using **recursion**.  

---

## Project Files

- Source file: `app/src/main/kotlin/org/example/first_excercice/App.kt`  
- Custom exception: `app/src/main/kotlin/org/example/first_excercice/Exception.kt`  
- Compiled JAR: `app/src/main/kotlin/org/example/first_excercice/App.jar`  

> Requires **JDK 17** to compile and run the JAR.

---

## Features

- **Decimal → Binary:** converts positive integers to binary recursively.  
- **Binary → Decimal:** converts a binary string to decimal recursively.  
- Input validation ensures only valid numbers are accepted.  
- Custom exception `InvalidBinaryException` handles invalid binary input.  
- Fully executable in the console.
